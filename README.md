# مكتب مدار النجوم للاستقدام — نسخة عرض (Vue 3 + Vite)

موقع عرض تجريبي ثنائي اللغة (عربي/إنجليزي) لمكتب مدار النجوم للاستقدام — حي المغرزات، الرياض.

## التشغيل
```bash
npm install
npm run dev
npm run build   # dist/
```
Vercel: Build `npm run build` — Output `dist`.

## الهوية
- من لوحة المكتب: خلفية عنابي/أسود ليلي + ذهبي، وشعار النجمة مع المدار (أعدنا رسمه SVG بشكل مبسط — يُستبدل بالشعار الأصلي عند توفره).
- خطوط: Reem Kufi + IBM Plex Sans Arabic، و Marcellus للإنجليزي.

## الأقسام
- طلب استقدام تفاعلي (المهنة ← الجنسية ← مواصفات ← البيانات) مع «تذكرة» ملخص حي، يُرسل إلى واتساب.
- «رحلة الطلب» على شكل مدار من 6 محطات قابلة للنقر.
- «تابع طلبك»: رقم عقد مساند + الاسم ← رسالة واتساب جاهزة.
- أسئلة شائعة، المكتب (الدوام والعنوان والخريطة)، رقمان: رقم Google ورقم اللوحة.

## المصادر
- خرائط Google: التقييم 4.0 (1,207)، الهاتف 050 212 3535، الدوام (الأحد–الخميس 9ص–5م)، العنوان والإحداثيات.
- صورة الواجهة من صور المكان على خرائط Google (اللوحة تحمل الرقم 058 216 3880 وشعار مساند).

## نقاط مهمة قبل العرض
- **لم نضع اقتباسات مراجعات**: أحدث المراجعات على Google فيها شكاوى من التأخير وضعف الرد على المتابعة. لذلك صُمم قسم «تابع طلبك» و«رحلة الطلب» ليعالجا هذه النقطة بالذات — وهي زاوية بيع قوية: «موقع يقلل اتصالات (وين وصل طلبي؟) ويحسن تقييمكم».
- صفحة المكان على Google مختلطة بصور ومراجعات مطعم مجاور (Gold Shrimp) وصور مكتب آخر (ركن عديم) — نقطة إضافية: نعرض عليهم تنظيف ملف Google Business.
- الجنسيات والمهن أمثلة شائعة، ونص الأسئلة الشائعة عام (يعتمد على العقد الموحد في مساند) — تُؤكَّد مع المكتب. لا توجد أسعار أو مدد محددة عمداً.
- رقم واتساب في النماذج = رقم Google (966502123535)؛ إن كان رقم اللوحة هو واتساب المكتب، غيّره في `src/data.js`.
- الموقع القديم madarstars.com يعطي خطأ شهادة SSL.

## قبل الإطلاق الرسمي
- احذف `<meta name="robots" content="noindex, nofollow">` من `index.html`.
- احذف شريط `.demo-ribbon` من `src/App.vue`.
